--------------------------------------------------------------------------------------------------------------------------METHODOLOGY
---------------------------------------------------------------------------------------------------------------------------The methodology adopted for this project involved the design, development, and 
implementation of an IoT-based smart irrigation system that automates plant watering 
using an ESP32 microcontroller. The process was divided into three main stages: system 
design and architecture, hardware development, and software implementation. 
1.System Design and Architecture 
The system was designed around the ESP32 microcontroller, which serves as the main 
processing and control unit. It has built-in Wi-Fi capability for real-time data 
transmission. The system includes various sensors such as: 
 DHT11 sensor – to measure temperature and humidity. 
 Three soil moisture sensors – to monitor the moisture level in the soil. 
 Water level sensor – to check the amount of water in the tank. 
These sensors continuously collect data from the environment, which is processed by the 
ESP32. Based on the readings, the controller decides whether to activate or deactivate the 
water pump through a relay module. The power supply converts 220V AC to DC, and a 
DC-DC buck converter ensures stable voltage for all components. The measured data is 
displayed on a 20x4 LCD screen and can also be viewed remotely through the Telegram 
mobile application using the ESP32’s Wi-Fi feature.

4. Operational Flow 
The system operates through the following steps: 
 Sensors collect data on soil moisture, temperature, humidity, and tank water level. 
 The ESP32 processes the data and displays it on the LCD. 
 If the soil moisture drops below the set threshold, the relay activates the pump for 
irrigation. 
 When the required moisture level is reached, the pump automatically turns off. 
 All data and system status are simultaneously available to the user through the 
Telegram app for remote monitoring.

7. DC Water Pump 
The DC pump is used for supplying water to the plants. When the soil moisture level 
drops below the set threshold, the relay activates the pump to start irrigation. Once the 
moisture reaches the required level, the pump automatically stops, conserving water.

8. LCD Display (20x4) 
The 20x4 LCD display is used to show real-time data such as soil moisture, temperature, 
humidity, and water level. It helps the user monitor the system locally without needing an 
internet connection. A pushbutton switch is attached to allow the user to toggle between 
different display screens.

9. Pushbutton Switch 
The pushbutton switch allows manual control of the display and other operations. When 
pressed, it sends a signal to the ESP32 to switch between display modes or start specific 
processes. 


Software and Communication Tools 
1. Arduino IDE 
The Arduino Integrated Development Environment (IDE) was used to write, compile, and 
upload the code to the ESP32 microcontroller. It supports libraries for the DHT11 sensor, 
LCD display, and Wi-Fi communication. 
2. Blynk IoT 
The Blynk IoT app was used for real-time monitoring and control through IoT. A Blynk 
IoT was created to communicate with the ESP32, allowing the user to receive sensor 
readings and send commands such as “/readings” or “/start”. 
3. Simulation Software 
Software such as Proteus and Fritzing were used for circuit design and simulation before 
actual hardware implementation. These tools helped verify circuit connections 
and system logic. 




 Summary 


The project followed a systematic approach involving the design, development, and 
testing of an IoT-based smart irrigation system using the ESP32 microcontroller. The 
system architecture was designed to monitor soil moisture, temperature, humidity, and 
water level using various sensors. These sensors provided real-time data to the ESP32, 
which processed the information and controlled a water pump through a relay module to 
automate irrigation. 
The hardware development included assembling components such as the ESP32 board, 
DHT11 sensor, soil moisture sensors, water level sensor, LCD display, and DC pumps. A 
DC-DC buck converter supplied stable power to the system, while the LCD displayed 
sensor data locally. The entire setup was housed in a protective enclosure for outdoor use. 
The software was developed using Arduino IDE, where the ESP32 was programmed to 
read sensor data, make irrigation decisions, and communicate via Wi-Fi. The Blynk IoT 
mobile application was integrated for remote monitoring and control, allowing users to 
view data and manage irrigation from anywhere. Before implementation, the system was 
simulated using Proteus software to verify circuit design and logic. 
This methodology ensured the successful creation of a smart, safe, and efficient irrigation 
system capable of reducing water wastage, improving monitoring accuracy, and 
promoting sustainable agricultural practices.
